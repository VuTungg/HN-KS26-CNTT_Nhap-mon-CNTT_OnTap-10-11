# AIHub – Quản lý các Model AI

![Logo AIHub](https://i.pinimg.com/736x/a3/69/9e/a3699ecd0a7956582b7f3670ee32b667.jpg)

Hệ thống **quản lý model** _trí tuệ nhân tạo_ chạy tại `web/index.html`.

| Thư mục | Nội dung                |
| ------- | ----------------------- |
| docs    | Tài liệu bàn giao       |
| data    | Bảng tính quản lý model |
| logs    | Log vận hành model AI   |
